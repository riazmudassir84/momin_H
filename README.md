# Love & Romance Calculator

A small browser-based entertainment app that generates playful Love and Romance scores for two names. It uses plain HTML, CSS, and JavaScript—no frameworks, dependencies, or build step.

> **For fun only:** the percentages are randomly generated. They do not measure real compatibility, feelings, or relationship outcomes.

## Features

- Generate a playful Love score for two names.
- Generate a separate Romance score.
- Responsive layout for desktop and mobile.
- Accessible input labels and live result announcements.
- Reduced-motion support.
- Runs locally in a modern browser with no installation.

## Run locally

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Enter both names and choose **Check Love %** or **Check Romance %**.

## Project structure

- `index.html` — app markup, styling, and JavaScript.

## How scoring works

Each button generates a random whole-number percentage from 0 to 100. The result is entertainment only and is not a scientific or predictive assessment.
